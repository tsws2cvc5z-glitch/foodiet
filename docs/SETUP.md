# Foodiet を公開して iPhone で使うまで

パソコンがなくても、iPhone の Safari だけで進められます（GitHub と Cloudflare の画面は、Safari の「デスクトップ用 Web サイトを表示」にすると操作しやすくなります）。

全体の流れ:

1. Cloudflare でデータベース（D1）を作る
2. GitHub の `wrangler.toml` にデータベースの ID を書く
3. Cloudflare Pages で GitHub のリポジトリを公開する
4. Cloudflare Access で自分だけが開けるようにする
5. iPhone のホーム画面に追加する
6. ヘルスケア連携のショートカットを作る

---

## 1. データベースを作る

1. https://dash.cloudflare.com でアカウントを作ってログインする（無料プランで足ります）
2. 左のメニューの「ストレージとデータベース」→「D1 SQL データベース」→「作成」
3. 名前に `foodiet` と入れて作成する
4. 作成したデータベースを開き、**データベース ID**（`xxxxxxxx-xxxx-...` の形）をコピーしておく
5. 「コンソール」タブを開き、このリポジトリの [`migrations/0001_init.sql`](../migrations/0001_init.sql) の中身をすべて貼り付けて実行する

## 2. wrangler.toml にデータベース ID を書く

1. GitHub でこのリポジトリの `wrangler.toml` を開き、鉛筆アイコン（Edit）を押す
2. `database_id = "00000000-0000-0000-0000-000000000000"` の部分を、1 でコピーした ID に書き換える
3. 「Commit changes」で保存する

## 3. Cloudflare Pages で公開する

1. Cloudflare の左メニュー「Workers & Pages」→「作成」→「Pages」タブ →「Git に接続」
2. GitHub と連携して、このリポジトリ（`foodiet`）を選ぶ
3. ビルドの設定:
   - プロジェクト名: `foodiet`（URL が `https://foodiet.pages.dev` になります。使われていたら別の名前に）
   - 本番ブランチ: `master`
   - フレームワーク プリセット: なし
   - ビルドコマンド: `npm run build`
   - ビルド出力ディレクトリ: `dist`
4. 「保存してデプロイ」

数分で `https://<プロジェクト名>.pages.dev` に公開されます。この時点では、まだ認証の設定がないので API はエラーになります（4 で設定します）。

### ショートカット用のトークンを設定する

1. 長くてランダムな文字列を用意する（例: iPhone のパスワード管理で「強力なパスワード」を作ってコピー）
2. Pages プロジェクトの「設定」→「変数とシークレット」→「追加」
   - 種類: シークレット
   - 名前: `API_TOKEN`
   - 値: 用意した文字列
3. この文字列は 6 のショートカットでも使うので、メモアプリなどに控えておく

## 4. 自分だけが開けるようにする（Cloudflare Access）

食事や体重の記録を他人に見られないよう、メールアドレスで本人確認してから開くようにします。

1. Cloudflare の左メニュー「Zero Trust」を開く（初回はチーム名を決めて、Free プランを選ぶ）
   - 決めたチーム名（`<チーム名>.cloudflareaccess.com` の部分）を控えておく
2. 「Access」→「アプリケーション」→「アプリケーションを追加」→「セルフホスト」
   - アプリケーション名: `Foodiet`
   - ドメイン: `<プロジェクト名>.pages.dev`（パスは空欄）
   - ポリシー: アクション「許可」、ルール「メール」に自分のメールアドレス
   - セッション時間: 1 か月（短いと、ログインし直す回数が増えます）
   - 保存したら、アプリケーションの「概要」にある **アプリケーション オーディエンス (AUD) タグ** をコピーする
3. もう一つアプリケーションを追加する（ショートカットはメール認証ができないので、ここだけ素通りさせる。代わりにアプリ側でトークンを確認します）
   - アプリケーション名: `Foodiet shortcut`
   - ドメイン: `<プロジェクト名>.pages.dev`、パス: `api/shortcut`
   - ポリシー: アクション「Bypass」、ルール「Everyone」
4. Pages プロジェクトの「設定」→「変数とシークレット」に、次の 2 つを追加する
   - `ACCESS_TEAM_DOMAIN`: 1 で決めたチーム名（`.cloudflareaccess.com` は付けない）
   - `ACCESS_AUD`: 2 でコピーした AUD タグ
5. Pages の「デプロイ」から最新のデプロイを「再試行」して、設定を反映させる

## 5. iPhone のホーム画面に追加する

1. Safari で `https://<プロジェクト名>.pages.dev` を開く
2. メールアドレスを入れて、届いたコードで認証する
3. 共有ボタン →「ホーム画面に追加」

以降はホーム画面のアイコンから開けます。最初に「はじめに」の画面で身長・体重・目標を入力してください。

## 6. ヘルスケア連携（ショートカット）

ヘルスケアのアクティブエネルギー・安静時エネルギー・体重を、1 日に数回このアプリへ送ります。Garmin を使う場合は、先に Garmin Connect アプリの「設定」→「接続されたアプリ」→「Apple ヘルスケア」で同期をオンにしておいてください。

### ショートカットを作る

「ショートカット」アプリで「＋」を押し、名前を **`Foodiet同期`** にします（アプリの「今すぐ同期」ボタンがこの名前で呼び出します）。次のアクションを順に追加します。

1. **ヘルスケアサンプルを検索**（Find Health Samples）
   - 種類: アクティブエネルギー
   - 条件: 開始日 が 今日
2. **統計を計算**（Calculate Statistics）: 「合計」、入力は 1 のヘルスケアサンプル
3. **変数を設定**（Set Variable）: 名前 `active`、入力は 2 の統計
4. 1〜3 と同じものを、種類「安静時エネルギー」・変数名 `resting` でもう一組作る
5. **ヘルスケアサンプルを検索**
   - 種類: 体重
   - 並び順: 開始日（新しい順）、制限: 1 件
6. **変数を設定**: 名前 `weight`、入力は 5 のヘルスケアサンプル
7. **URL の内容を取得**（Get Contents of URL）
   - URL: `https://<プロジェクト名>.pages.dev/api/shortcut/health`
   - 方法: POST
   - ヘッダ: キー `Authorization`、値 `Bearer <3 で決めた API_TOKEN>`
   - 本文を要求: JSON
     - `active`（数字）: 変数 `active`
     - `resting`（数字）: 変数 `resting`
     - `weight`（数字）: 変数 `weight`
8. **辞書の値を取得**（Get Dictionary Value）: キー `reminder`、入力は 7 の結果
9. **if**: 8 の辞書の値が「任意の値」のとき
   - **通知を表示**（Show Notification）: 8 の辞書の値
10. 手動で実行したときに残りカロリーを見たい場合は、9 の後ろに「辞書の値を取得」（キー `remaining`）と「通知を表示」を追加する

一度手動で実行すると、ヘルスケアへのアクセス許可を求められるので「許可」してください。アプリの「今日のサマリー」で「ヘルスケアの最終同期」が更新されていれば成功です。

### 自動で実行する

「ショートカット」アプリの「オートメーション」→「＋」→「時刻」で、次の時刻にそれぞれ作ります。

| 時刻 | 目的 |
|---|---|
| 7:00 | 朝の時点の値（借金の確定にも使う） |
| 12:00 | 朝食の入力忘れの通知 |
| 15:00 | 昼食の入力忘れの通知 |
| 21:30 | 夕食の入力忘れの通知 |
| 23:55 | その日の最終的な消費カロリー |

いずれも「繰り返し: 毎日」「すぐに実行」を選び、実行するショートカットに `Foodiet同期` を選びます。

入力忘れの通知は、10 時を過ぎて朝食、14 時を過ぎて昼食、21 時を過ぎて夕食の記録がないときに出ます。食べなかった食事は、食事登録画面の「○○は食べなかった」で記録すると通知が止まります。

### 送る値について

`/api/shortcut/health` は次の項目を JSON かフォームで受け取ります。すべて省略できます。

| 項目 | 内容 |
|---|---|
| `active` / `resting` | 今日のアクティブ・安静時エネルギー（kcal） |
| `yesterday_active` / `yesterday_resting` | 昨日の分（送れる場合） |
| `weight` | 最新の体重（kg）。その日にアプリで手入力した体重は上書きしません |
| `date` | 「今日」として扱う日付（`YYYY-MM-DD`、省略時は日本時間の今日） |

返り値は `{ "remaining": "今日はあと650kcal食べられます", "reminder": "昼食が未入力です" }` の形です。

## 困ったとき

- **「Cloudflare Access が設定されていません」と出る**: 4 の `ACCESS_TEAM_DOMAIN` と `ACCESS_AUD` を設定して、再デプロイしてください
- **ショートカットが `unauthorized` になる**: ヘッダの `Bearer ` の後ろの文字列が `API_TOKEN` と一致しているか、4-3 の Bypass の設定があるか確認してください
- **データベースのエラーが出る**: 1-5 の SQL を実行したか、2 の ID が正しいか確認してください
- **バックアップ**: 設定画面の「データを書き出す」で、すべての記録を JSON でダウンロードできます
